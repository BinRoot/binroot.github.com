Choose an action → simulate a future → check the outcome

Choose

Start from the current state. Apply one candidate action.

Simulate

Follow fixed rules for later actions and random events, for H steps.

Score

Return 1 if the final state meets the objective, otherwise 0.

Repeat from the same starting state and action. The average outcome estimates its chance of success.

This pattern fits intervention, maintenance, and resource-allocation simulators. Each supplies its own rules and objective.
