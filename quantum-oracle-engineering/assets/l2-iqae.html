Use repeated measurements to narrow the possible angles.

1. Run a circuit

Prepare with A. Apply Q a chosen number of times. Measure the payoff bit.

2. Collect results

Repeat that circuit with fresh preparations. Count how often the bit is 1.

3. Refine the estimate

Update the interval for θ. Choose the next number of Q applications and repeat.

Stop when the interval for a = sin²θ is narrow enough.

Measurements happen between circuits. Each coherent sequence uses A and A† without measuring inside it.
